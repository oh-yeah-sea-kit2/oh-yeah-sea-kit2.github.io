プライバシーポリシー

夢札（以下「本アプリ」）は、個人開発者 oh-yeah-sea-kit2（以下「開発者」）が提供するカードゲームです。本アプリで扱う情報と、その使い方を説明します。

  • 氏名・メールアドレス・位置情報・連絡先・写真など、あなたを特定できる情報は集めません。
  • 広告は表示しません。課金もありません。
  • あなたの行動を他社のアプリやサイトをまたいで追跡（トラッキング）しません。

1. 集める情報と目的

情報中身目的
端末ごとの識別子本アプリが作る乱数の ID。端末の広告 ID やアカウントとは結び付けません「旅人の夢」でデッキを預ける・ほかの人のデッキと戦うため
ゲームの内容預けたデッキ、段位、旅人の夢での戦績「旅人の夢」のため
利用状況どの画面を開いたか、練習戦・対戦・パックを開けた回数と時刻、アプリのエラー。自由に入力した文字は送りません遊びにくい所や不具合を見つけて直すため（翌日も遊ばれているか、どこでやめたかを見る）

集めた札・デッキ・進み具合などのゲームのデータは、あなたの端末の中に保存されます。

2. 情報の保存先

上の情報は、開発者が Cloudflare 上に置いた自前のサーバに保存します。第三者に売ったり、渡したりしません。法令に基づく開示の求めがある場合を除きます。

3. 情報の削除

アプリを削除すると、端末の中のゲームのデータは消えます。サーバに預けた情報の削除を希望する場合は、下の連絡先までご連絡ください。

4. 子どもの利用

本アプリは子どもを主な対象にはしていません。子どもの個人情報を意図して集めることはありません。

5. このポリシーの変更

内容を変える場合は、このページで知らせます。
