2. 本ポリシーの適用範囲

本ポリシーは本サービスに適用されます。本アプリが利用する第三者のサービス（広告、サインイン、アプリ内課金、地図データなど。詳しくは「6. 第三者への提供・委託先」）における取り扱いは、それぞれの事業者のプライバシーポリシーに従います。

アプリのバージョンについて：本ポリシーは、バージョン 3.0.0 で追加される機能を含めて記載しています。3.0.0 より前のバージョンをお使いの場合、次の機能はまだ提供されておらず、これらに関する情報の取得・送信も行われません。

  • 利用状況データの送信（4.1）
  • Google／Apple アカウントとの連携（4.3）
  • じぶんビンゴのクラウド保存、公開ギャラリーへの公開・取り込み、通報（4.2・4.4）
  • 連続おさんぽ記録のクラウド同期（4.4）

3. 端末内にのみ保存される情報

本アプリのデータの多くは、当方のサーバーではなくお使いの端末内に保存されます。以下は、本ポリシーで別途送信すると記載しているものを除き、当方のサーバーへ送信されません。

  • 進行中・過去のビンゴの記録、達成状況、メダル、図鑑
  • 本アプリで撮影した写真（ゲーム中のものも、じぶんビンゴのマスに使ったものも含みます）
  • じぶんビンゴのマスに描いたお絵かきの画像データ（そのカードを公開申請しない限り）
  • 表示設定（漢字／ひらがなの切り替えなど）、その他のアプリ内設定
  • エラーメッセージの原文・スタックトレース（端末内のログにのみ出力され、外部へ送信されません）

撮影した写真の画像データは、当方のサーバーへ送信されません。公開ギャラリーにカードを公開する場合も送信されず、写真そのものが他の方に見られることはありません（4.5）。

じぶんビンゴのカードをクラウドに保存する場合、写真・お絵かきを使ったマスについては、クラウド上のカード情報に画像を識別するためのハッシュ値のみが含まれます（画像そのものは含まれません）。

お絵かきの画像データのみ、そのカードを公開申請された場合に当方のサーバーへ送信します。取り扱いは4.5をご確認ください。

4. 取得する情報と利用目的

4.1 利用状況データ（行動ログ）

本アプリは、品質向上と改善のため、匿名の利用状況データを当方のサーバー（Cloudflare社のインフラ上で当方が運用するもの）へ送信します。

送信する情報：

  • 計測用の匿名ID（analyticsId）：本アプリが端末内で生成するランダムな識別子です。一度生成されると、アプリを削除するか、利用状況データの送信をオフにするまで同じ値が使われ続けます（セッションごとに変わるものではありません）。送信をオフにすると、この識別子は端末から消去され、再びオンにした場合は新しい識別子が生成されます。
  • 端末・アプリの基本情報：プラットフォーム（iOS／Android）、アプリのビルド番号、OSのメジャーバージョン、ひらがな表示モードのオン／オフ、「おうえんパス」購入の有無
  • 操作の記録：画面の表示・遷移、ボタン操作やゲーム内の操作イベント（ゲーム開始、ビンゴ達成、写真撮影の成否など）、エラーの種別

送信しない情報：

  • 氏名・メールアドレス・生年月日・年齢
  • 位置情報の緯度経度（「近くを探す」機能については、見つかった件数と結果の区分のみを送信し、座標は送信しません）
  • 写真・お絵かきの画像データ
  • カードのタイトル、マスに入力した文章、通報の自由記述など、お客様が入力した文章の原文
  • エラーメッセージ・スタックトレースの原文（エラーの種別のみを送信します）
  • アカウントの識別子、クラウド同期用の端末識別子、広告識別子（IDFA／AAID）

送信できるイベントの種類と項目はサーバー側であらかじめ定義された一覧に限定されており、一覧にない項目は受け付けません。計測用の匿名IDは、アカウントの識別子やクラウド同期用の端末識別子とは別に生成・保存され、当方はこれらを突き合わせる仕組みを設けていません。

利用目的（自動改善ループ）：本アプリの改善を継続的に回すため、次の流れで利用します。

  1. 上記の利用状況データを計測・記録する
  2. 日次で集計し、個人を特定できない統計値（利用者数、画面ごとの離脱、エラー発生率など）にする
  3. その統計値をもとに、AIサービス（Anthropic社のClaude API）で週次の分析レポートを生成する
  4. レポートを当方が確認し、次の改善に反映する

AIサービスへ渡すのは上記2で作成した集計値のみであり、個々の操作記録・識別子・お客様が入力した文章を渡すことはありません。生成されたレポートは当方内部での確認にのみ用い、外部へ公開しません。

送信の停止（オプトアウト）：利用状況データの送信は既定でオンになっていますが、本アプリの「設定」→「おとなのメニュー」→「利用状況データの送信」からいつでもオフにできます。オフにすると、それ以降のデータは送信されず、計測用の匿名IDも端末から消去されます。

4.2 公開ギャラリーの閲覧・取り込み（アカウント連携なしでも行われる処理）

以下は、Google / Apple とのアカウント連携をしていない状態でも当方のサーバーに送信・保存されます。

(1) 匿名アカウントの自動作成：本アプリで公開ギャラリーを開いた時点で、本アプリは当方のサーバーに対して匿名のアカウントを自動的に作成します（アカウント連携は不要で、確認画面も表示されません）。このとき当方のサーバーに保存されるのは次のとおりです。

  • 当方が発行する利用者識別子（ランダムな値）と、作成日時
  • クラウド同期用の識別子（4.8のとおり、本アプリが端末内で生成するランダムな値です。端末のハードウェア固有IDや広告識別子ではありません）
  • サインイン状態を保持するためのトークンの照合用データ（トークンそのものではなく、そのハッシュ値）と、その発行日時・有効期限

この匿名アカウントには、氏名・メールアドレスは含まれません（連携していないため、当方はこれらを受け取っていません）。

(2) 公開カードの取り込み：公開ギャラリーのカードをご自身のカードとして取り込むと、そのカードのタイトルと25マスそれぞれのテキストが、あなたのアカウントのカードとして当方のサーバーに保存されます。これはアカウント連携の有無にかかわらず行われます。

(3) 取り込み履歴：あわせて、どの公開カードを、どの利用者識別子が、いつ取り込んだかの記録を保存します。目的は、同じカードの二重取り込みを防ぐこと、公開カードごとの取り込み数を数えること、および不正利用への対応です。

これらはいずれも、9.のアカウント削除によって削除できます。アカウント連携をしていない場合でも、アプリ内の削除手順は連携済みの場合と同じです（アカウント削除のご案内）。

4.3 アカウント連携（任意）

じぶんビンゴのクラウド保存や公開ギャラリーへの公開申請をご利用いただく場合は、Googleアカウントまたは Apple ID との連携が必要です。連携すると、当方は次の情報をサーバーに保存します。

  • サインイン提供元から受け取る識別子（sub）
  • メールアドレス（Apple でサインインの場合、Appleの「メールを非公開」により提供される転送用アドレスとなることがあります）
  • サインイン状態を保持するためのトークン、および当方が内部で発行する利用者識別子

利用目的は、お客様の端末とクラウドの間でデータを同期すること、公開申請の本人性・責任所在を明確にすること、および不正利用への対応です。連携は任意で、連携しなくても本アプリのビンゴ・図鑑・じぶんビンゴの作成（端末内保存）はご利用いただけます。

4.4 じぶんビンゴのクラウド保存

アカウント連携済みの場合、ご自身で作成したじぶんビンゴのカードが当方のサーバーに保存されます。保存される内容は、カードのタイトル、25マスそれぞれの内容（お客様が自由に入力した文章の原文を含みます）、およびカードの状態（下書き／保護者承認済み／公開申請中など）です。目的は、機種変更・再インストール時の復元と、端末間での同期です。

なお、公開ギャラリーから取り込んだカードは、アカウント連携をしていない場合でも当方のサーバーに保存されます（4.2）。

4.5 公開ギャラリー（ユーザー投稿コンテンツ・UGC）

公開ギャラリーは現在準備中で、ご利用いただけません。本項は、公開を開始したあとの取り扱いをあらかじめお知らせするものです。準備が整い次第、本ページの最終更新日を改めてお知らせします。
公開申請したカードの内容は、不特定多数の方が閲覧できる状態になります。
  • 公開されるのは、カードのタイトル、各マスのテキスト、および各マスに描かれたお絵かきの画像です。
  • 作成者を特定できる情報は公開しません。ギャラリーの表示にも、当方が提供するAPIの応答にも、作成者の氏名・メールアドレス・利用者識別子は含めません（無記名）。
  • 写真は公開されません。写真を使ったマスを含むカードも公開できますが、公開されるのはそのマスに入力されたテキストだけです。写真の画像データは当方のサーバーへ送信されないため、公開用のデータに写真を参照する項目そのものが存在せず、写真が公開経路に流れることはありません。
  • お絵かき（本アプリ内で描いた絵）は公開されます。公開申請をすると、その画像データが当方のサーバーへ送信されます。取り扱いは以下のとおりです。
    • 審査を通過するまで、画像は他の方から一切取得できません。審査待ち・却下・公開停止中・公開取り下げ後の画像は、URLをご存じであっても取得できません。画像を配信するかどうかは、リクエストのたびに「公開中のカードから参照されているか」を確認して判断します。
    • 審査担当者は、承認の前に必ず実際の画像を確認します。
    • 保存前に、画像に付随しうるメタデータ（撮影記録等）を当方のサーバーで自動的に削除します。
    • カードを削除された場合、およびアカウントを削除された場合は、画像の実体を当方のストレージから削除します。
  • お絵かきに描く内容にご注意ください。お名前・住所・学校名など、ご本人を特定できる情報を絵の中に書き込まないようご確認ください。当方の審査で気づけないものもあります。
  • 公開は審査制です。保護者の承認に加え、当方による自動フィルタと人手の審査を通過したもののみが公開されます。
  • いったん公開されたカードを他の利用者が自分の端末に取り込んだ場合、そのコピーは、あとから公開を取り下げても相手側に残ります。当方はこれを取り消すことができません。

本項はカードを公開する側の取り扱いです。公開ギャラリーを見る側・取り込む側で当方のサーバーに保存される情報は、4.2をご確認ください。

公開ギャラリーのご利用条件は、別途ユーザー投稿コンテンツ（UGC）利用規約に定めます。

4.6 通報

公開されたカードを通報していただくと、当方は通報者の利用者識別子、通報の区分、自由記述（最大200文字）、通報の日時、対象のカードを記録します。目的は、不適切なコンテンツへの対応、再発防止、および紛争が生じた場合の対応です。通報された内容は、対象カードの作成者に開示しません。

4.7 連続おさんぽ記録

アカウント連携済みの場合、本アプリで遊んだ日付の履歴を当方のサーバーに保存します。ホーム画面を表示した際に自動で同期されます。目的は、機種変更後も連続記録が引き継がれるようにすることです。日付以外の情報（遊んだ場所や内容など）は含みません。

4.8 端末識別子

本アプリは2種類の識別子を端末内で生成します。いずれもランダムな値で、端末のハードウェア固有IDや広告識別子ではありません。

  • クラウド同期用の識別子：アカウント連携やクラウド保存の際に、当方のサーバーが端末を識別するために使います。
  • 計測用の匿名ID（analyticsId）：4.1のとおり、利用状況データにのみ付随します。

いずれも、本アプリをアンインストールするまで端末内に保持されます（計測用の匿名IDは、利用状況データの送信をオフにした時点でも消去されます）。

4.9 IPアドレス

当方のサーバーは、通信の性質上、送信元のIPアドレスを受け取ります。IPアドレスは不正な大量アクセスを防ぐためのカウンタ（レート制限）の識別キーとしてのみ利用し、その保存期間は最大2日間です（カウンタの集計単位に応じて自動的に消去されます）。IPアドレスを利用状況データの一部として保存・分析することはなく、他の目的にも利用しません。

4.10 位置情報

本アプリには、周辺の施設を探す「近くを探す」機能があります。

  • この機能を実行し、表示される確認ダイアログで同意された場合にのみ、端末の位置情報（緯度経度）を取得し、OpenStreetMapの検索サービス（Overpass API、および必要に応じて Nominatim）へ送信して周辺の施設を検索します。
  • これらの外部サービスへ送信するのは、おおよその位置（緯度・経度を小数第3位までに丸めた座標。緯度でおよそ110メートル、日本付近の経度でおよそ90メートルの粒度）です。端末から取得した精密な座標をそのまま送信することはありません。検索範囲は半径約2キロメートルのため、この丸めによって検索結果が実用上変わることはありません。
  • この機能をお使いにならない場合、位置情報が外部へ送信されることはありません。
  • 取得した緯度経度は検索のためにのみ用い、当方のサーバーには送信・保存しません。精密な座標は端末内での距離計算にのみ使い、端末の外には出ません。
  • 利用状況データに含まれるのは、検索の結果区分（見つかった／見つからなかった／エラー等）と件数のみで、座標は含みません。

4.11 アプリ内課金

本アプリには、広告を非表示にする「おうえんパス」（support_pass）と、3種類の「なげ銭」（tip_small / tip_medium / tip_large）があります。決済および購入の記録は、Apple および Google のアプリ内課金の仕組みを通じて行われ、当方はクレジットカード番号等の決済情報を取得しません。購入の有無（おうえんパスを保有しているかどうか）は端末内に保持され、当方のサーバーでレシートの検証を行うことはありません。なお、おうえんパスの保有状況は、4.1のとおり利用状況データに真偽値として含まれます。

4.12 広告

本アプリは、おうえんパスを購入されていない場合に Google AdMob の広告を表示します。広告SDKは、広告の配信・不正防止・効果測定のために、IPアドレスや端末に関する情報等を収集することがあります。詳しくは「6. 第三者への提供・委託先」および Google のポリシーをご確認ください。

5. 保護者の方による操作の確認

本アプリでは、判断や同意を伴う操作（アプリ内課金、アカウント連携、アカウント削除、公開申請、通報、利用状況データの送信の切り替えなど）を、簡単な計算問題による確認画面（「おとなのかくにん」）の奥に配置しています。これは、これらの操作がお子様だけの操作で行われないようにするための仕組みです。年齢を確認するための仕組みではなく、当方が年齢・生年月日を取得することはありません。

7. データの保管地域と国外への移転

当方のサーバーは Cloudflare のグローバルなネットワーク上で稼働しており、データベース（Cloudflare D1）はアジア太平洋地域を優先する設定で作成していますが、物理的な保管地域を特定の国に固定することは保証できません。また、週次レポートの生成に用いる Anthropic 社のサービスは米国の事業者が提供するものであり、集計値は米国へ移転されます。これらの国・地域の個人情報保護制度は日本と異なる場合があります。本サービスをご利用いただくことで、これらの移転が生じることをご了承ください。
